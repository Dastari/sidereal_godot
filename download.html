Sidereal, in Godot.

A native client connected to the same authoritative world. Your server and database remain on Sidereal; this build runs locally on Windows.

Download for Windows x64

Native evaluation 0.2.0. Includes Dastari sign-in, character entry, server-validated movement, Tetris inventory, equipment, five item hotbar slots and tooltips. Shared windows resize and move; colors, transparency and scale are configurable. Login and crew selection render an interim 3D hangar. Replacement character art, full shared-space presentation and asset streaming remain in development.

Run on Windows

  1. Connect Tailscale using the account that has access to the Sidereal server.
  2. Download the ZIP, then use Extract all. Keep every extracted file and folder together.
  3. Open Sidereal.exe. The exported game includes its runtime; you do not need to install Godot or .NET.
  4. Select Sign in with Dastari, complete sign-in in your browser, then return to the game and select Resume character or Enter world.
  5. Use WASD to take control and move or pilot. Shift sprints, E uses a nearby pilot station and Escape releases control.
  6. Open Inventory or Character from the top bar. Drag items, press R while dragging to rotate, and use 1–5 for item hotbar actions. The Interface window controls theme and layout.

Use the same Dastari account as the browser game to retain your character. Taking control transfers input between clients on that account. Windows execution and GPU performance still need verification on your machine.

Edit the project

For ongoing development, clone Dastari/sidereal_godot and check out feat/native-spacetimedb-client. Install Godot 4.7.2 .NET and .NET SDK 8.0.425, then import the root project.godot. The standard Godot build cannot compile this C# client.

The source ZIP below is also available for a one-off download. It contains Sidereal/project.godot. Use Git for exchanging AI changes and editor work; save and commit local work before pulling.
