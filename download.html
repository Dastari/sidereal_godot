Sidereal, in Godot.

A native client connected to the same authoritative world. Your server and database remain on Sidereal; this build runs locally on Windows.

Download for Windows x64

Native evaluation 0.4.0. Includes Dastari sign-in, character entry, walking, piloting, contextual interaction, combat and EVA input, Tetris inventory, equipment, scoped storage and tooltips. Shared windows resize and move; theme, display and graphics preferences are saved locally. Login and crew selection use a 3D dock. Released crew models, armor, faces and animations appear in the world and paper doll. Known stock ships render their replicated layout; shared space includes disclosed vessels, reviewed planet/moon appearances, starfield, dust and accepted engine exhaust. Lighting calibration, some effects and editing interfaces, custom construction, asset streaming and Windows/GPU acceptance remain open. Run on Windows

  1. Connect Tailscale using the account that has access to the Sidereal server.
  2. Download the ZIP, then use Extract all. Keep every extracted file and folder together.
  3. Open Sidereal.exe. The exported game includes its runtime; you do not need to install Godot or .NET.
  4. Select Sign in with Dastari, complete sign-in in your browser, then return to the game and select Resume character or Enter world.
  5. Use WASD to walk or pilot, Shift to sprint, E to use nearby objects or a control seat, and X for cruise or EVA suit hold. V toggles combat; aim with the mouse, click to fire and R to reload.
  6. Use I for inventory, C for character, N for navigation and Tab for deck/flight view. Drag items and press R while dragging to rotate. Keys 1–5 invoke assigned item actions; 9/0 inspect quick items.
  7. Escape cancels or opens the six-tab system menu. Display and Graphics save local preferences. Right drag and the wheel control the camera outside interface panels.

Use the same Dastari account as the browser game to retain your character. Taking control transfers input between clients on that account. Windows execution and GPU performance still need verification on your machine.

Edit the project

For ongoing development, clone Dastari/sidereal_godot and check out feat/native-spacetimedb-client. Install Godot 4.7.2 .NET and .NET SDK 8.0.425, then import the root project.godot. The standard Godot build cannot compile this C# client.

The source ZIP below is also available for a one-off download. It contains Sidereal/project.godot. Use Git for exchanging AI changes and editor work; save and commit local work before pulling.
